# macrdp Surak v0.10.9.1

This fork release builds on upstream v0.10.9. The GitHub release and downloads
use v0.10.9.1. The binaries retain the upstream-compatible 0.10.9 version.

- **Stable 1080p/60** uses H.264 AVC420 over TCP, a 60 Mbps adaptive encoder
  target, one frame in flight, and standard flush cadence. Wired Windows
  Remote Desktop testing covered fast typing, document scrolling, restoring
  a minimized session, and video playback with audio. The encoder target
  guides bitrate control. Actual payload can exceed it during motion.
- **4K/60 Preview** offers direct NV12 capture and two frames in flight.
  Sharp Text (LAN) offers a higher encoder target for a wired link. Both 4K
  profiles are experimental.
- **Controller** offers a compact profile menu, a preview of changed video
  settings before Apply, and separate capture and TCP write timings in
  Performance. Performance profiles preserve the keyboard shortcut settings.
- **Keyboard and screenshots** include improved Space switching and language
  switching. Remote Cmd+Shift+3/4 follow the Mac Screenshot save destination.
  Add Ctrl to copy one capture to the Mac clipboard.
