# macrdp Surak v0.96.1

A pre-release of SurakTH's fork, based on upstream macrdp v0.9.6. This release
updates both the Rust server and the native macOS Controller. The fork now uses
its own version sequence; upstream v0.9.7–v0.9.11 features and fixes are not
implicitly included. Original authors retain full credit; see CREDITS.md.

## Video and Controller

- Send trailing H.264 pictures at the normal frame cadence while retaining the
  quiet-period IDR recovery path. Windows typing tests reported improved response.
- Recover encoder pipeline slots after dropped VideoToolbox callbacks, including
  AVC444 frame pairs, and request an IDR to restore encoder continuity.
- Add the Stable 1080p profile: AVC420, 60 FPS, adaptive 25 Mbps, TCP, normal flush.
- Add optional fast flush with an editable 8–1000 ms interval. The Controller
  initially selects 10 ms when enabling it; normal flushing remains the default.
- Add physical capture presets from 720p to 4K plus custom even dimensions,
  independently of virtual-display size. CAPTURE_SIZE pins physical capture size.
- Validate settings before Apply, preserve explicit config overrides over legacy
  EXTRA_FLAGS, and keep Revert available for unsaved edits.
- Distinguish saved settings from live session dimensions and the capture FPS
  limit. Detect externally started servers to avoid a competing Controller start.
- Retain the existing self-healing LaunchAgent and native Controller workflow.

## Reliability and security

- Sanitize redirected-drive mount names, create private mount directories, and
  handle disconnects during an in-flight mount with bounded helper execution.
- Store Keychain passwords through native Security APIs instead of command-line
  arguments; preserve access controls on password updates.
- Replace smart-card loopback TCP IPC with a private Unix socket and peer checks.
  The privileged IFD handler verifies the server owner recorded by its installer.
- Move legacy installer logs into the user's Library and escape plist values.
- Align the declared Rust toolchain with CI (1.95.0).

## Upgrade

Install **both macrdp.app and macrdp Controller.app** from the DMG. Existing user
configuration is retained. Check Screen Recording and Accessibility grants if
macOS requests them after replacing an ad-hoc signed build. CI distribution
bundles are ad-hoc signed, not notarized.

**Smart-card users must reinstall the bundled IFD handler with the updated
server.** The old TCP handler is incompatible with the new Unix-socket bridge.
See [smart-card upgrade instructions](https://github.com/SurakTH/macrdp/blob/v0.96.1/docs/smart-card-redirection.md#ipc-authentication-and-upgrading).

Choose **Connection → Stable → Apply** for the 1080p starting point. Apply
restarts a running managed server; reconnect afterward. Fast flush is optional.

## Validation and limits

Local verification: 248 Rust tests passed (4 ignored), 36 Swift tests passed,
IFD handler tests and disposable-Keychain integration passed, and macOS clippy
with warnings denied passed. Server and Controller packages built and passed
strict code-signature verification. Native UI checks confirmed preset values,
resolution choices, invalid-value blocking and Revert.

Windows mstsc testing covered earlier video builds: stable flushing improved
perceived typing latency; fast flush felt faster but produced more image
artifacts. The final packaged build has not yet completed a fresh Windows
end-to-end session or extended soak test. Fast flush remains experimental;
AVC444 still has known gray/pink corruption on tested mstsc clients. No claim of
RemoteFX-equivalent latency or artifact-free fast flushing is made.
