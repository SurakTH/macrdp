# macrdp Surak v0.9.6.2

This pre-release updates the macrdp server and menu-bar Controller. Cargo
and the macOS bundles report internal version 0.96.2.

## Changes

- Personal presets and a Performance page with live video and ACK telemetry,
  reused captures, and encoder and dispatch diagnostics.
- Editable resolution, bitrate, H.264 queue depth, and Fast flush interval.
  Responsive capture can prefer a newer queued capture. TCP video pacing is
  opt-in.
- H.264 repaint on restore from minimize, keyframe recovery on frame
  submission and dispatch errors, and updated handling of dynamic resize.
- Release held keys and mouse buttons when an RDP transport disconnects.
  Improve wheel direction changes and mouse modifier handling.
- Cancel pending clipboard startup work on disconnect and avoid fetching
  clipboard data promised by Apple Universal Clipboard.
- Check the macOS account password before saving it, verify the managed
  listener on startup, and export Windows RDP shortcuts from Controller.

## Windows validation

1080p/60 was exercised with Windows Remote Desktop, including keyboard and
mouse input, minimize and restore, and clipboard copy and paste in a live
session. Clipboard sync after reconnect and the latest recovery fixes still
need additional live testing. 4K at a 60 FPS capture setting showed
intermittent picture corruption during scrolling in earlier preview trials.
Start with the Stable profile for daily work.

## Upgrade

Install the matching server and Controller from the same release. A server
restart interrupts active sessions. macOS may request Screen Recording and
Accessibility again for the new build. Verify downloaded assets against
`SHA256SUMS`.
