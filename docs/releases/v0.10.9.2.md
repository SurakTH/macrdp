# S' MacRDP v0.10.9.2

## What changed

- **Stable 1080p/60** keeps H.264 over TCP and allows two frames in flight. This is the starting profile for everyday use.
- **H.265 (HEVC) Preview** adds 1080p/60, 1440p/60 and 4K/60 profiles for compatible clients, with H.264 fallback where supported. The 4K profile uses TCP pacing to limit the queue when the client falls behind.
- **Controller** adds separate HEVC profile controls and shows the active codec in Performance. The README includes a Windows App screenshot from the 4K HEVC test.
- **PCM audio** sends uncompressed stereo audio at 44.1 kHz in 10 ms packets. On macOS 14.2 and later, enable Core Audio Tap with `AUDIO_CORE_TAP=1` in `config.env` to try lower capture latency. The Tap path can queue up to 120 ms of PCM during a brief network write stall. ScreenCaptureKit is the default capture path. AAC remains available.

## Tested with Windows App

Windows App negotiated HEVC in a direct wired 4K session and reported 58 FPS in one motion test. In the later PCM + Core Audio Tap build, the server logged no PCM queue drops during a 69-second 4K test. The 4K HEVC profiles and Core Audio Tap remain opt-in previews.

## Install or update

Use the Apple Silicon DMG from this release and copy both apps to Applications. Open **macrdp Controller** and start the server. If macOS requests permissions, grant Screen Recording and Accessibility to the installed `macrdp.app`, then restart it from the Controller. If the server points to an old location, use **Status → Repair Installation**.

The GitHub tag and download names use `v0.10.9.2`. The binaries retain the upstream-compatible `0.10.9` version.
